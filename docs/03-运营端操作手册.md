# 运营端操作手册（`/console`）

Ledger Hub 运营后台是内嵌单页（`internal/iface/http/console.html`），由 API 进程提供。用于查账、启停、冲正、对账关单和触发 Worker 作业。**没有加减余额按钮**；纠错走冲正，冻结走 Capture/Release。

---

## 1. 打开与登录

| 入口 | 鉴权 |
|------|------|
| `http://127.0.0.1:8080/console` | 直连 API，可不填 Token |
| `http://127.0.0.1:8088/console` | 经 Gateway，必须带运营 Token |

Gateway 配置 `gateway.console_token`，本地默认 **`dev-console-token`**。只接受请求头 `X-Console-Token`。**禁止**查询参数 `console_token`（避免进浏览器历史和访问日志）。对账文件下载走 `fetch` + 同一请求头，再以 blob 保存。

操作人请求头 **`X-Operator`**（登录框「操作人」，如 `ops_zhang`）。会写入：冲正、Capture/Release、关闭差异、手动作业。未填时后端默认为 `console`。

登录页说明：经网关须填 Token；直连 `:8080` 可不填。进入后顶栏可改租户、操作人、Token，点「保存」写入 `localStorage`（键：`ledger_console_token` / `ledger_console_operator` / `ledger_console_tenant`）。

顶栏租户下拉对应 `X-Tenant-Id`。演示租户：

| tenant_id | 名称 | 状态 |
|-----------|------|------|
| `t_default` | 默认租户 | active |
| `t_mall` | 商城租户 | active |
| `t_legacy` | 历史租户 | disabled（记账会拒） |

## 2. 金额展示

后台按资产 `precision` 格式化最小单位整数（`fmtAmt`）：

| 资产 | precision | 库内 / API | 页面展示 |
|------|-----------|------------|----------|
| POINT、COIN | 0 | `7050` | `7050` |
| BALANCE_CNY | 2 | `1049900` | **`10499.00`** |
| BALANCE_USD | 2 | `14000` | **`140.00`** |

Capture 弹窗会同时给出展示金额和「最小单位」。**提交的 `amount` 必须是最小单位整数**（例如确认 15.00 元 CNY 应填 `1500`，不要填 `15.00`）。

## 4. 模块说明

侧栏对应 hash：`#/dashboard` `#/assets` `#/tenants` `#/accounts` `#/entries` `#/freezes` `#/fx` `#/reconcile` `#/jobs` `#/audit` `#/risk`。

### 4.1 概览

接口：`GET /api/v1/ledger/console/overview`。

卡片：租户数、资产数、账户数、汇率快照数、限额告警数。下列最近告警与资产摘要。

### 4.2 资产

- **登记**：`POST /api/v1/ledger/assets`。字段：`asset_code`、`name`、`asset_class`、`holder_types`（逗号分隔，默认 `user,merchant`）、`freeze_supported`。
- **下线 / 启用**：`POST /api/v1/ledger/assets/{asset_code}/disable|enable`。下线后记账报「资产未启用」。
- 列表来自 overview。点「选用」填入表单。

种子资产：POINT（`ext.expire.policy=year_end`）、BALANCE_CNY/USD/HKD、COIN、GROWTH（演示已 disable）。

### 4.3 租户

- 保存：`POST /api/v1/ledger/tenants`，`{"tenant_id","name","status":"active"}`。
- 停用 / 启用：`POST /api/v1/ledger/tenants/{id}/disable|enable`。停用后 `Ensure` 返回「租户已停用」。

### 4.4 账户

- 查询：`GET /api/v1/ledger/accounts?holder_id=&holder_type=&asset_code=`。不填 holder 则列当前租户账户。
- 开户：`POST /api/v1/ledger/accounts/open`，`{"holder":{"type","id"},"asset_code"}`。
- 停用 / 启用：`POST /api/v1/ledger/accounts/{account_id}/disable|enable`。停用后禁止记账（「账户已停用」）。
- 行内「流水」跳到流水页并带上 holder。

可用 / 冻结按精度展示。不要指望在本页改数字。

### 4.5 流水

- 优先 `biz_no`：`GET /api/v1/ledger/entries?biz_no=`。
- 否则按 holder 分页：`limit=50`，上一页 / 下一页改 `offset`。
- 「凭证」：`GET /api/v1/ledger/journals/{journal_id}`。
- **冲正**：`POST /api/v1/ledger/commands/reverse`

```json
{
  "source_system": "wallet",
  "biz_no": "ops:reverse:{原biz_no}:{时间戳}",
  "related_biz_no": "原 biz_no"
}
```

`source_system` 默认 `wallet`（须在 ACL 内）。新号可手填，否则页面自动生成。原流水保留。不能对冲正单再冲正。

页面提示：**禁止直接改余额。**

### 4.6 冻结单

- 按人：`GET /api/v1/ledger/freezes?holder_id=&holder_type=&asset_code=&status=`
- 过期待释放：`GET /api/v1/ledger/freezes?expired=1&limit=50`
- 在途：`GET /api/v1/ledger/freezes?status=frozen`

仅 `frozen` 行有按钮：

| 按钮 | 命令 | source_system | 说明 |
|------|------|---------------|------|
| 确认 | Capture | `order` | 可填部分金额（最小单位）；空 = 整单 |
| 释放 | Release | 过期队列用 `worker`，其余用 `order` | 冻额退回 available |

Capture 示例 body：

```json
{
  "source_system": "order",
  "biz_type": "ops_capture",
  "biz_no": "ops:capture:{freeze_id}:{timestamp}",
  "freeze_id": "fz_...",
  "asset_code": "POINT",
  "amount": "1500"
}
```

部分 Capture 后冻结单金额改为余量，状态仍为 `frozen`。整单确认 → `captured`；释放 → `released`。

超时释放也可在「作业」点「释放过期冻结」（Worker 每 30s 也会跑）。

### 4.7 汇率

`POST /api/v1/ledger/fx/rates`：

```json
{
  "base_asset": "BALANCE_CNY",
  "quote_asset": "BALANCE_USD",
  "rate": "0.14000000",
  "rate_source": "manual",
  "created_by": "console"
}
```

账本只存快照。Worker `fx_feed` 会写 `rate_source=feed` 的 CNY→USD `0.14000000`。兑换可引用 `rate_id`（演示 `fxr_demo_cny_usd`）。

### 4.8 对账

- 触发：`POST /api/v1/ledger/reconcile/jobs`，`{"date":"YYYY-MM-DD","source_system":"","asset_code":""}`。不传业务清单也会跑 L2 余额勾稽、L3 冻结、L4 兑换完整性。
- 按日查看：`GET /api/v1/ledger/reconcile/reports/{date}?source_system=&asset_code=`
- 任务：`GET /api/v1/ledger/reconcile/jobs?limit=20`，点「查看」拉 `GET .../jobs/{id}`
- **待关闭差异**：`GET /api/v1/ledger/reconcile/diffs?limit=50`
- 关闭：`POST /api/v1/ledger/reconcile/diffs/{id}/resolve`，`{"note":"已补 Capture"}`。响应含 `resolved_by`（X-Operator）。**关单不等于改账**；少账要业务补命令，多账要 Reverse。
- 文件：`GET /api/v1/ledger/reconcile/files`，下载 `GET .../files/{name}`（带 `X-Console-Token`，不要把 token 放进 URL。目录 `app.reconcile_dir`，本地 `data/reconcile`，Docker `/tmp/ledger-reconcile`）
- 跨分片在途会出现差异类型 `cross_shard_inflight`（`pending_settlement` 有余额）。到作业页查看 Saga。

演示对账会为当天 `campaign`+`POINT` 造一笔 `missing`：业务清单含 `campaign:demo:ghost`。

### 4.9 作业

`POST /api/v1/ledger/ops/jobs/{name}`，body 对 `reconcile` 为 `{"date":"YYYY-MM-DD"}`（页面用当天 UTC 日期），其余 `{}`。

| name | 作用 | 与 Worker 对应 |
|------|------|----------------|
| `release_expired` | 扫描过期冻结并 `Release`（`source_system=worker`） | 每 30s |
| `reconcile` | 对每个 **active** 租户 Trigger 日终 | 每 1h，默认对**昨天**；控制台手动用当天 |
| `expire` | 按资产 `ext.expire` 把可用余额 Transfer 到 `point_sink` | 每 24h；`year_end` 仅在 1 月 1–2 日过账 |
| `fx_feed` | 写入配置的汇率对 | 每 1h |
| `idempotency` | 删除早于 `idempotency_retain`（192h）的幂等记录 | 每 1h |
| `saga` | 续跑未完成跨分片 Transfer Saga | 每 15s |

未知 `{name}` → `40001`「未知作业」。结果写入 `GET /api/v1/ledger/ops/jobs`。

作业页同时列出 Saga：`GET /api/v1/ledger/ops/sagas?status=`（空=未完成）。人工 `POST /ops/sagas/{id}/retry`、`POST /ops/sagas/{id}/compensate`。状态：`pending` / `out_done` / `in_done` / `compensating` / `completed` / `failed`。

**过期试算**（不记账）：`GET /api/v1/ledger/ops/jobs/expire/preview?as_of=YYYY-MM-DD`。页面默认填明年 `01-01`，便于看到 POINT `year_end` 将清掉的可用额。`rolling_days` 按 Credit 入账日滚动。系统科目账户不参与过期。

### 4.10 审计

| 块 | 接口 |
|----|------|
| 网关审计 | `GET /api/v1/ledger/ops/audits?limit=50`（client_id / tenant_id / method / path / status） |
| 运营操作 | `GET /api/v1/ledger/ops/actions?limit=50`（operator / action / target） |
| 限额告警 | `GET /api/v1/ledger/ops/alerts?limit=50` |

会记操作人的动作：`Reverse`、`Capture`、`Release`、`resolve_diff`、`job:{name}`、`saga_retry`、`saga_compensate`。

### 4.11 风控

- **重载 ACL / 限额**：`POST /api/v1/ledger/ops/reload`。改 `configs/config.yaml` 后点此，或等 API **15s** 扫描文件 mtime。
- 展示当前 ACL 与限额（单笔 / 日累计按精度展示）。wallet Debit POINT 单笔上限展示为 `80`。
- 超限告警与概览同源。

## 5. 常用 curl（运营）

直连 API 示例。经网关时加 `-H 'X-Console-Token: dev-console-token'`，不要把 token 放进 query。

```bash
# 概览
curl -s http://127.0.0.1:8080/api/v1/ledger/console/overview \
  -H 'X-Tenant-Id: t_default' -H 'X-Operator: ops_zhang'

# Alice 账户
curl -s 'http://127.0.0.1:8080/api/v1/ledger/accounts?holder_type=user&holder_id=u_alice'

# 待关闭差异
curl -s 'http://127.0.0.1:8080/api/v1/ledger/reconcile/diffs?limit=50'

# 关闭差异（不改余额）
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/reconcile/diffs/DIFF_ID/resolve \
  -H 'Content-Type: application/json' -H 'X-Operator: ops_zhang' \
  -d '{"note":"已人工核对，业务侧已补账"}'

# 过期试算
curl -s 'http://127.0.0.1:8080/api/v1/ledger/ops/jobs/expire/preview?as_of=2027-01-01'

# 手动释放过期冻结
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/ops/jobs/release_expired \
  -H 'Content-Type: application/json' -H 'X-Operator: ops_zhang' -d '{}'
```

## 6. 不要做的事

1. **禁止直接改余额**（无 SQL、无「调账加减」接口）。纠错：`Reverse`；冻结：Capture / Release。
2. 不要把关闭对账差异当成补账。关单只改工单状态。
3. 不要在后台做任意 Credit/Debit。流水页只有冲正；冻结页只有确认/释放。
4. 不要对 `u_dormant`、下线资产 `GROWTH`、停用租户 `t_legacy` 强行记账。
5. Capture 金额填最小单位整数，不要填带小数的展示值。
6. 不要把 `dev-console-token` 用于生产；生产应替换 `gateway.console_token`。不要把 Token 放进 URL query。
7. 库存、订单状态、支付渠道路由、券码、会员等级不在本后台，也不要当已交付能力运营。
