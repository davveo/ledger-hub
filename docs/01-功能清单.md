# Ledger Hub 功能清单

对照当前代码（`internal/iface/http`、`internal/gateway`、`internal/application`、`configs/config.yaml`）。只列**已交付**能力。

本中台是虚拟资产记账内核，不替代订单、支付、库存、营销。下列能力**不在范围且未实现**：库存、订单状态机、支付渠道路由、券码生命周期、会员等级。后台**不做任意 Credit/Debit**；纠错走 `Reverse`。

使用方式：

- 业务系统接入：[C端操作手册.md](./C端操作手册.md)
- 运营后台 `/console`：[运营端操作手册.md](./运营端操作手册.md)
- OpenAPI：`GET /api/v1/ledger/openapi.yaml`

金额一律最小单位整数，JSON 用字符串。`POINT` precision 0（`7050` = 7050 分）；`BALANCE_CNY` / `BALANCE_USD` precision 2（`1049900` = `10499.00`）。余额恒等式：`total = available + frozen`。

默认租户 `t_default`。生产流量走 Gateway `:8088`（HMAC V2，迁移期兼容 V1）；本地可直连 API `:8080`。按 ID 查询必须带当前租户，跨租户一律 `40401`。

## 1. C 端记账命令

接入方：`order` / `pay` / `campaign` / `wallet`（经 Gateway 的 `client_id`）。Worker 用 `source_system=worker` 做超时释放与过期，不对外签发密钥。

| 命令 | 路由 | 做什么 | 谁用 |
|------|------|--------|------|
| Credit | `POST /api/v1/ledger/commands/credit` | 入账：用户 available↑，系统科目 `point_issuance` OUT | campaign（POINT）、pay（BALANCE_CNY）、wallet |
| Debit | `POST /api/v1/ledger/commands/debit` | 出账：用户 available↓，系统科目 `point_sink` IN | wallet（POINT 单笔上限 80）；worker 过期不走 Debit |
| Freeze | `POST /api/v1/ledger/commands/freeze` | 预占：available↓ frozen↑，生成冻结单 | order（POINT / BALANCE_CNY）、wallet |
| Capture | `POST /api/v1/ledger/commands/capture` | 确认预占：frozen↓；可部分 Capture，余量继续冻 | order、wallet；运营台冻结单「确认」 |
| Release | `POST /api/v1/ledger/commands/release` | 释放预占：frozen↓ available↑ | order、wallet、worker（超时释放） |
| Transfer | `POST /api/v1/ledger/commands/transfer` | 同币种转账；跨分片经 `system_subject:pending_settlement` 两段，持久化 Saga 可续跑/补偿 | wallet；worker 过期入 `point_sink` |
| Exchange | `POST /api/v1/ledger/commands/exchange` | 同一 holder 跨币种兑换，一笔 Journal | wallet（POINT / BALANCE_CNY / BALANCE_USD） |
| Reverse | `POST /api/v1/ledger/commands/reverse` | 按原 `biz_no` 整笔冲正，保留原流水 | wallet；运营台流水页 |

聚合入口：`POST /api/v1/ledger/commands`，body 带 `"command":"Credit"` 等。

成功：`{"code":0,"data":{...}}`。同一 `tenant + source_system + biz_no + command` 重试且参数一致时 `idempotent_replay=true`。

## 2. 查询

| 能力 | 路由 | 做什么 | 谁用 |
|------|------|--------|------|
| 查账户 | `GET /api/v1/ledger/accounts?holder_type=&holder_id=&asset_code=` | 指定资产返回单账户；无 `asset_code` 返回该持有人全部币种；无 `holder_id` 列租户账户 | 业务查余额、运营台账户页 |
| 按 ID 查账户 | `GET /api/v1/ledger/accounts/{account_id}` | 账户详情（available/frozen 为字符串最小单位） | 运营 / 排障 |
| 账户流水 | `GET /api/v1/ledger/accounts/{account_id}/entries` | 该账户全部分录 | 运营台 |
| 流水 | `GET /api/v1/ledger/entries?biz_no=` 或 `holder_id` + `limit/offset` | 按业务单或持有人查流水；可选 `from`/`to`（RFC3339）。非法时间、`from >= to`、跨度超过 366 天返回 `40021`–`40024`（`error` 如 `TIME_FROM_INVALID`） | 业务对账、运营台流水页 |
| Journal | `GET /api/v1/ledger/journals/{id}` | 凭证 + 分录 | Transfer / Exchange / Reverse / 入账凭证 |
| 冻结单 | `GET /api/v1/ledger/freezes/{freeze_id}` | 单笔冻结 | Capture/Release 前定位 |
| 按业务号查冻结 | `GET /api/v1/ledger/freezes?biz_no=` | 订单锁单 | order Connector |
| 按持有人列冻结 | `GET /api/v1/ledger/freezes?holder_id=&status=` | 分页列冻结单 | 运营台 |
| 过期冻结队列 | `GET /api/v1/ledger/freezes?expired=1` | 已过 `expire_at` 仍 frozen | 运营台 / Worker |
| 在途冻结 | `GET /api/v1/ledger/freezes?status=frozen` | 当前租户 frozen 列表 | 运营台 |
| 资产 | `GET /api/v1/ledger/assets`、`GET .../assets/{asset_code}` | 资产定义（精度、可否冻结） | 接入与运营 |
| 汇率 | `GET /api/v1/ledger/fx/rates`、`GET .../fx/rates/{rate_id}` | 列表或按 `base`+`quote` 取当前快照 | wallet 兑换、运营台 |
| 租户 | `GET /api/v1/ledger/tenants`、`GET .../tenants/{id}` | 租户列表 / 详情 | 运营台 |
| 健康检查 | `GET /livez` 存活；`GET /readyz` 就绪（API/Worker ping MySQL 主库与分片）；`GET /healthz` 为 liveness 别名；`GET /metrics` Prometheus | 部署探针 / 监控 |

分页：`limit` 默认 50，最大 200。

## 3. 对账

| 能力 | 路由 | 做什么 | 谁用 |
|------|------|--------|------|
| 触发日终 | `POST /api/v1/ledger/reconcile/jobs` | **202** 入队（`queued`）。唯一键 `(tenant, date, source, asset, job_type, version)`；默认复用 queued/running/done。`force_new_version=true` 或 `POST .../jobs/{id}/rerun` 升版本。Worker 领取执行 | 业务日终、运营台、Worker |
| 任务列表 | `GET /api/v1/ledger/reconcile/jobs` | 最近对账任务 | 运营台 |
| 任务详情 | `GET /api/v1/ledger/reconcile/jobs/{id}` | 摘要 + 差异 | 运营台 |
| 按日报告 | `GET /api/v1/ledger/reconcile/reports/{date}` | 按日期取报告，可选 `source_system`、`asset_code` | 运营 / 业务 |
| 文件列表 | `GET /api/v1/ledger/reconcile/files` | `app.reconcile_dir` 下 CSV | 运营下载 |
| 下载文件 | `GET /api/v1/ledger/reconcile/files/{name}` | 附件下载 | 运营 |
| 待关闭差异 | `GET /api/v1/ledger/reconcile/diffs` | 状态 `open` 的工单 | 运营台 |
| 关闭差异 | `POST /api/v1/ledger/reconcile/diffs/{id}/resolve` | 只关工单，**不改余额**；记录 `closed_by`/`closed_at` | 运营 |
| 指派差异 | `POST /api/v1/ledger/reconcile/diffs/{id}/assign` | `{assignee, note}`，写事件 | 运营 |
| 差异事件 | `GET /api/v1/ledger/reconcile/diffs/{id}/events` | assign/note/resolve 历史 | 运营 |
| 强制重跑 | `POST /api/v1/ledger/reconcile/jobs/{id}/rerun` | 新版本入队，202 | 运营 |

不传 `biz_lines` 也会跑 L2 余额勾稽、L3 冻结勾稽、L4 兑换完整性，以及 pending_settlement 跨分片在途扫描。差异类型：`extra` / `missing` / `amount_mismatch` / `asset_mismatch` / `balance_tie_out` / `freeze_tie_out` / `fx_incomplete` / `channel_mismatch` / `cross_shard_inflight`。

## 4. 运营台与运维接口

页面：`GET /console`（API `:8080` 直连免登录；经 Gateway `:8088` 必须带请求头 `X-Console-Token`，默认 `dev-console-token`。**禁止** `?console_token=`）。

| 能力 | 路由 / 页面 | 做什么 | 谁用 |
|------|-------------|--------|------|
| 概览 | `GET /api/v1/ledger/console/overview` | 租户、资产、账户、汇率、ACL、限额、告警汇总 | 运营「概览」 |
| 资产登记 / 启停 | `POST /assets`、`POST /assets/{code}/disable\|enable` | 注册资产、下线后禁止记账 | 运营「资产」 |
| 租户保存 / 启停 | `POST /tenants`、`POST /tenants/{id}/disable\|enable` | 停用租户后记账返回无权 | 运营「租户」 |
| 开户 / 账户启停 | `POST /accounts/open`、`POST /accounts/{id}/disable\|enable` | 显式开户；停用账户禁止变动 | 运营「账户」 |
| 流水检索与冲正 | 流水页 → `POST /commands/reverse` | 新 `biz_no` + `related_biz_no` | 运营「流水」 |
| 冻结 Capture / Release | 冻结单页 → `POST /commands/capture\|release` | 确认走 `order`，超时释放走 `worker` | 运营「冻结单」 |
| 汇率快照 | `POST /api/v1/ledger/fx/rates` | 只存快照，不负责行情对错 | 运营「汇率」、Worker Feed |
| 作业手动触发 | `POST /api/v1/ledger/ops/jobs/{name}` | `release_expired` / `reconcile` / `expire` / `fx_feed` / `idempotency` / `saga` / `queued-reconcile`。多副本靠 `ledger_job_lease` 互斥 | 运营「作业」 |
| 跨分片 Saga | `GET /ops/sagas`，`POST /ops/sagas/{id}/retry\|compensate` | 查询、人工续跑、人工补偿 | 运营「作业」 |
| 过期试算 | `GET /api/v1/ledger/ops/jobs/expire/preview?as_of=` | 不记账，列出将过期金额 | 运营「作业」 |
| 作业记录 | `GET /api/v1/ledger/ops/jobs` | `items` + 各作业 `last_success`；Run 含 instance_id / duration_ms / last_error / attempt | 运营 |
| 网关审计 | `GET /api/v1/ledger/ops/audits` | Gateway 请求审计 | 运营「审计」 |
| 运营操作 | `GET /api/v1/ledger/ops/actions` | 冲正 / Capture / Release / 关差异 / 手动作业 | 运营「审计」 |
| 限额告警 | `GET /api/v1/ledger/ops/alerts` | 超限落库告警 | 运营「审计」「风控」 |
| ACL/限额热加载 | `POST /api/v1/ledger/ops/reload` | 重读 yaml，写入 `ledger_config_revision`；`GET /ops/config/revisions` | 运营「风控」 |

运营台**没有**任意加减余额按钮。纠错：冲正；冻结：Capture/Release。

## 5. 网关、Worker、Connector

| 能力 | 入口 | 做什么 | 谁用 |
|------|------|--------|------|
| HMAC 鉴权 | Gateway `:8088`，头 `X-Client-Id` / `X-Timestamp` / `X-Signature`；V2 另需 `X-Sign-Version` / `X-Nonce` / `X-Key-Version` | 读写均需签。V2 覆盖 method/path/query/tenant/ts/nonce/body hash；nonce 窗口内不可重复（`40102`）。`source_system` 必须等于 `client_id`；client 绑定 `tenants`；时间窗 300s。迁移期 V1/V2 共存 | 全部业务系统 |
| 运营 Token | 同上，**仅** `X-Console-Token` | 浏览器进 `/console`；对账文件用 fetch + 请求头下载 | 运营 |
| 按 client 限流 | Gateway 秒桶 | 全局默认 200 RPS；order/pay 本地配置 80 | 防打爆 |
| 超时释放冻结 | Worker 每 30s | `Release`，`biz_no=worker:expire:{freeze_id}` | 系统 |
| 跨分片 Saga | Worker 每 15s | 扫描 `pending/out_done/in_done/compensating`，续跑或补偿 | 系统 |
| 日终对账 | Worker 每 1h（租约互斥） | 按唯一键入队前一天任务，另有 `queued-reconcile` 领取 queued | 系统 |
| 积分过期 | Worker 每 24h | `year_end` / `rolling_days`；Transfer 到 `point_sink` | 系统；POINT 种子为 `year_end` |
| 汇率 Feed | Worker 每 1h | 写入 `BALANCE_CNY→BALANCE_USD` `0.14000000` | 系统 |
| 幂等清理 | Worker 每 1h | 删除超过 `idempotency_retain`（192h）的记录 | 系统 |
| 订单样板 | Connector `:8090` `POST /connector/order/events` | `created→Freeze`、`paid→Capture`、`cancelled→Release` | 订单系统接入参考 |
| 支付样板 | `POST /connector/pay/events` | `paid→Credit`；`refund→Credit`（pay ACL 仅允许 Credit） | 支付系统接入参考 |
| 文件/HTTP MQ | `POST /connector/mq/events` 或 `data/mq/*.json` | 先写 `ledger_mq_inbox`（message_id 幂等），再处理；失败退避，超限 `dead`。`GET /connector/mq/inbox`，`POST .../inbox/{id}/replay` | 本地联调 / 失败治理 |
| Kafka | `connector.kafka.brokers` 非空时启动 | `Consumer` 插件，`github.com/segmentio/kafka-go`；测试不依赖 Kafka | 生产可选 |

## 7. 权限矩阵（`configs/config.yaml` → `acl.rules`）

内核强制校验。越权返回 `40301`。

| source_system | 允许命令 | 允许资产 |
|---------------|----------|----------|
| campaign | Credit | POINT |
| order | Freeze, Capture, Release | POINT, BALANCE_CNY |
| pay | Credit | BALANCE_CNY |
| wallet | Credit, Debit, Freeze, Capture, Release, Transfer, Exchange, Reverse | POINT, BALANCE_CNY, BALANCE_USD |
| worker | Release, Debit, Transfer, Reverse | `*` |

限额（`limits.rules`）：wallet Exchange 单笔 `100000000`、日累计 `1000000000`、日笔数 1000；wallet Debit POINT 单笔上限 **80**。超限 `42901` 并写告警。

## 8. 生产运行（P1）

| 能力 | 说明 |
|------|------|
| 版本化 migration | `cmd/migrate`（`make migrate` / `bin/ledger-migrate`）。记录 `ledger_schema_migration`。`mysql.auto_migrate` 本地/docker 为 true；**生产 `app.env=prod` 默认 false**，须先跑 migrate Job |
| Schema 演进 | **expand**（新列可空 / 新表）→ **migrate**（回填）→ **contract**（加约束、删旧列）。勿在同一发布里加 NOT NULL 并填历史 |
| 密钥外置 | yaml 加载后再 overlay：`LEDGER_GATEWAY_CONSOLE_TOKEN`、`LEDGER_GATEWAY_CLIENT_<CLIENTID>_SECRET`（大写，连字符变下划线）。prod 拒绝空 token、`dev-console-token`、空或 `dev-` 前缀 secret。日志不打印密钥 |
| 配置热加载审计 | 重载 ACL/限额写入 `ledger_config_revision`（version / operator / checksum / payload）；`GET /ops/config/revisions` |
| Prometheus | `GET /metrics`：HTTP 按 method+path+status；命令按 command+result；Saga pending/oldest（Worker tick 刷新）；Worker 作业耗时/失败。不在请求热路径刮库 |
| 链路 | 默认 no-op；`OTEL_EXPORTER_OTLP_ENDPOINT` 非空才导出 OTLP。始终传播 W3C `traceparent`。Gateway 转发 `X-Request-Id` 与 `traceparent`。日志字段：`request_id` / `trace_id` / `tenant_id` / `client_id`，记账时还有 `biz_no` / `journal_id` |
| Worker 租约 | 表 `ledger_job_lease`；实例 ID = hostname+pid。ticker 前 Acquire，运行中续期，过期可接管。`worker.lease_ttl` 默认 30s |
