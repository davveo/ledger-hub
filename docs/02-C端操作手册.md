# C 端操作手册（业务系统接入）

面向 **order / pay / campaign / wallet** 以及样板进程 **connector**。账本只认标准记账命令，不认「下单」「签到」等业务语义（语义放 `biz_type`）。

生产流量必须走 **Gateway `:8088`**。直连 API `:8080` 无 HMAC，仅限本机开发。

OpenAPI：`GET http://127.0.0.1:8080/api/v1/ledger/openapi.yaml`  
Go SDK：`pkg/client`。

---

## 1. 鉴权（Gateway HMAC）

配置见 `configs/config.yaml` → `gateway.clients`（Docker 为 `configs/config.docker.yaml`，密钥相同）。

| client_id | secret（本地） | 本地 RPS |
|-----------|----------------|----------|
| order | `dev-secret-order` | 80 |
| pay | `dev-secret-pay` | 80 |
| campaign | `dev-secret-campaign` | 全局 200 |
| wallet | `dev-secret-wallet` | 全局 200 |

写、读 `/api/*` **都要签名**。`/console` 可用运营 Token（见运营手册）。

### 1.1 请求头

| Header | 说明 |
|--------|------|
| `X-Client-Id` | 必须是上表之一 |
| `X-Timestamp` | Unix 秒。与服务器偏差超过 `max_skew_seconds`（默认 **300**）拒绝 |
| `X-Signature` | `HMAC-SHA256(secret, client_id + timestamp + body)` 的 hex |
| `Content-Type` | `application/json` |
| `X-Tenant-Id` | 可选；缺省 `t_default`。也可放 JSON `tenant_id` |
| `X-Request-Id` | 可选；响应回显 |

签名算法与 `pkg/sign/sign.go` 一致：先写 `client_id+timestamp`，再写 **原始 body 字节**（GET 时 body 为空）。

**硬约束：JSON 里的 `source_system` 必须与 `X-Client-Id` 完全一致**，否则 Gateway 返回 `40301`「source_system 必须与 client_id 一致」。未知 `client_id` / 缺签名 / 时间窗 / 签名失败均为 `40100`。

### 1.2 签名 curl 示例

```bash
CLIENT=campaign
SECRET=dev-secret-campaign
TS=$(date +%s)
BODY='{"source_system":"campaign","biz_type":"signin","biz_no":"campaign:signin:u123:20260817","holder":{"type":"user","id":"u_123"},"asset_code":"POINT","amount":"100"}'
SIG=$(printf '%s' "${CLIENT}${TS}${BODY}" | openssl dgst -sha256 -hmac "$SECRET" | awk '{print $2}')

curl -s -X POST http://127.0.0.1:8088/api/v1/ledger/commands/credit \
  -H 'Content-Type: application/json' \
  -H "X-Client-Id: ${CLIENT}" \
  -H "X-Timestamp: ${TS}" \
  -H "X-Signature: ${SIG}" \
  -d "$BODY"
```

GET 查询同样要签（body 为空）：

```bash
CLIENT=wallet
SECRET=dev-secret-wallet
TS=$(date +%s)
SIG=$(printf '%s' "${CLIENT}${TS}" | openssl dgst -sha256 -hmac "$SECRET" | awk '{print $2}')
curl -s "http://127.0.0.1:8088/api/v1/ledger/accounts?holder_type=user&holder_id=u_alice&asset_code=POINT" \
  -H "X-Client-Id: ${CLIENT}" \
  -H "X-Timestamp: ${TS}" \
  -H "X-Signature: ${SIG}"
```

本机调试可省略签名，直连 `http://127.0.0.1:8080`（下列命令示例默认直连 API）。

## 2. 金额、租户、持有人

- 金额：**最小单位整数**，JSON 字符串。`POINT` precision **0**：`"100"` = 100 分。`BALANCE_CNY` / `BALANCE_USD` precision **2**：`"1049900"` = **10499.00** 元。
- 禁止用浮点传金额。账本 `parseAmount` 只接受十进制整数。
- `holder.type`：`user` / `merchant` / `system_subject`。系统科目由内核写入（`point_issuance`、`point_sink`、`fx_fee_income`、`fx_clearing`、`pending_settlement`），业务不要自造。
- 懒开户：Credit/Debit/Freeze 时若账户不存在会自动开。也可 `POST /api/v1/ledger/accounts/open`。
- 停用账户 / 下线资产 / 停用租户后记账失败（`40001` 或 `40301`）。
- `GROWTH` 演示数据已下线，不能再记账。wallet ACL **不含** `BALANCE_HKD` / `COIN`。

## 3. `biz_no` 与幂等

建议：`{source_system}:{biz_type_short}:{natural_id}`

```text
campaign:signin:u123:20260817
order:freeze:O20260814001
pay:credit:P988331
wallet:fx:F20260814001
wallet:reverse:campaign:demo:carol:point
```

规则：

1. 同一业务动作重试，**`biz_no` 不变**。
2. 幂等键：`tenant_id + source_system + biz_no + command`。参数一致 → 回放首次结果，`idempotent_replay=true`。参数不一致 → `40901`。
3. 逆向业务用**新号**，`related_biz_no` 指向原单（Capture/Release/Reverse）。
4. 禁止用一次性随机 UUID 当业务键（除非业务库已持久化该号）。
5. Worker 超时释放使用 `worker:expire:{freeze_id}`，不要与订单 `Release` 抢同一 `biz_no`。

---

## 4. ACL：谁能调什么

内核按 `source_system + command + asset_code` 校验（`internal/application/acl.go`）。越权 `40301`。

| 接入方 | 命令 | 资产 |
|--------|------|------|
| **campaign** | Credit | POINT |
| **order** | Freeze / Capture / Release | POINT、BALANCE_CNY |
| **pay** | Credit | BALANCE_CNY |
| **wallet** | Credit / Debit / Freeze / Capture / Release / Transfer / Exchange / Reverse | POINT、BALANCE_CNY、BALANCE_USD |

限额：wallet `Debit` POINT 单笔 **≤ 80**；wallet `Exchange` 单笔 ≤ `100000000`、日累计 ≤ `1000000000`、日笔数 ≤ 1000。超限 `42901`。

campaign **不能** Debit/Freeze；pay **不能** Reverse/Debit（样板退款仍走 Credit，见第 10 节）。order **不能** Credit（支付入账由 pay 做）。

## 5. 统一请求体与响应

公共字段（`commandDTO`）：

```json
{
  "command": "Credit",
  "request_id": "可选",
  "tenant_id": "t_default",
  "source_system": "campaign",
  "biz_type": "signin",
  "biz_no": "campaign:signin:u123:20260817",
  "holder": {"type": "user", "id": "u_123"},
  "asset_code": "POINT",
  "amount": "100",
  "freeze_id": "",
  "related_biz_no": "",
  "to_holder": null,
  "from": null,
  "to": null,
  "fee": null,
  "fx": null,
  "tolerance": "0",
  "expire_at": "2026-08-20T00:00:00Z",
  "ext": {}
}
```

`expire_at`、`fx.quoted_at` 为 RFC3339。

成功 `data`：

```json
{
  "accepted": true,
  "idempotent_replay": false,
  "freeze_id": "fz_...",
  "journal_id": "jnl_...",
  "entry_ids": ["ent_..."],
  "account": {"account_id": "acc_...", "available": "7050", "frozen": "600"},
  "to_account": null
}
```

账户查询的 `available` / `frozen` 也是**字符串最小单位**。

## 6. 命令示例

下列 curl 直连 `:8080`。生产请按第 1 节加签并改 `:8088`。

### 6.1 campaign · Credit（积分发放）

ACL：仅 POINT。Credit 会写 `journal_type=posting`，并对 `system_subject:point_issuance` 记一笔 OUT。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/credit \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "campaign",
    "biz_type": "signin",
    "biz_no": "campaign:signin:u123:20260817",
    "holder": {"type": "user", "id": "u_123"},
    "asset_code": "POINT",
    "amount": "100"
  }'
```

### 6.2 pay · Credit（支付到账入余额）

`"10000"` = **100.00** 元。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/credit \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "pay",
    "biz_type": "pay_credit",
    "biz_no": "pay:credit:P988331",
    "holder": {"type": "user", "id": "u_123"},
    "asset_code": "BALANCE_CNY",
    "amount": "10000"
  }'
```

### 6.3 order · Freeze / Capture / Release

下单锁积分。`expire_at` 到期后 Worker 自动 Release。

```bash
# Freeze
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/freeze \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "order",
    "biz_type": "order_freeze",
    "biz_no": "order:freeze:O20260814001",
    "holder": {"type": "user", "id": "u_123"},
    "asset_code": "POINT",
    "amount": "50",
    "expire_at": "2026-08-20T00:00:00Z"
  }'
```

支付成功确认。可用 `freeze_id` 或 `related_biz_no` 定位冻结单。`amount` 省略或 0 = 整单；大于 0 且小于剩余冻结 = **部分 Capture**，余量仍为 `frozen`。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/capture \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "order",
    "biz_type": "order_capture",
    "biz_no": "order:capture:O20260814001",
    "related_biz_no": "order:freeze:O20260814001",
    "holder": {"type": "user", "id": "u_123"},
    "asset_code": "POINT",
    "amount": "30"
  }'
```

取消必须 Release，**禁止**另开一笔 Credit 补偿。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/release \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "order",
    "biz_type": "order_release",
    "biz_no": "order:release:O20260814001",
    "related_biz_no": "order:freeze:O20260814001",
    "holder": {"type": "user", "id": "u_123"},
    "asset_code": "POINT"
  }'
```

非 `frozen` 状态再 Capture/Release → `42202`。

### 6.4 wallet · Debit

POINT 单笔不得超过 80（演示限额）。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/debit \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "wallet",
    "biz_type": "consume",
    "biz_no": "wallet:consume:u_alice:D1",
    "holder": {"type": "user", "id": "u_alice"},
    "asset_code": "POINT",
    "amount": "50"
  }'
```

### 6.5 wallet · Transfer（同币种）

禁止跨 `asset_code`（请用 Exchange）。跨 `holder_id` 分片时内核拆成两段：先转到 `system_subject:pending_settlement`（`biz_no` 加 `:xshard:out`），再转入对方（`:xshard:in`）；第二腿失败会 Reverse 第一腿。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/transfer \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "wallet",
    "biz_type": "gift",
    "biz_no": "wallet:gift:alice-bob:1",
    "holder": {"type": "user", "id": "u_alice"},
    "to_holder": {"type": "user", "id": "u_bob"},
    "asset_code": "POINT",
    "amount": "10"
  }'
```

### 6.6 wallet · Exchange（跨币种）

同一 holder。`rate` 含义：`to_display ≈ from_display * rate`。账本用资产精度换算期望 `to_amount`，若 `|expected - to.amount| > tolerance` 返回 `42203`。`to.amount` 可省略，由账本按汇率计算。

手续费记用户 OUT + `system_subject:fx_fee_income` IN；轧差走 `system_subject:fx_clearing`。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/exchange \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "wallet",
    "biz_type": "fx_convert",
    "biz_no": "wallet:fx:F20260817001",
    "holder": {"type": "user", "id": "u_alice"},
    "from": {"asset_code": "BALANCE_CNY", "amount": "10000"},
    "to":   {"asset_code": "BALANCE_USD", "amount": "1400"},
    "fx": {"rate": "0.14000000", "base_asset": "BALANCE_CNY", "quote_asset": "BALANCE_USD", "rate_source": "manual"},
    "fee": {"asset_code": "BALANCE_CNY", "amount": "10"},
    "tolerance": "0"
  }'
```

也可只传 `fx.rate_id`（如演示 `fxr_demo_cny_usd`），由账本读快照。兑换冲正必须整笔 Journal `Reverse`，不要只改一侧。

### 6.7 wallet · Reverse（冲正）

新 `biz_no` + `related_biz_no` = 原单。原流水保留。不能对冲正流水再冲正。若原单有 Journal，按该 Journal 全部分录回滚。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/commands/reverse \
  -H 'Content-Type: application/json' \
  -d '{
    "source_system": "wallet",
    "biz_type": "correct",
    "biz_no": "wallet:reverse:campaign:demo:carol:point",
    "related_biz_no": "campaign:demo:carol:point"
  }'
```

运营台冲正默认也走 `source_system=wallet`（须符合 ACL）。

## 7. 查询

```bash
# 单币种
curl -s 'http://127.0.0.1:8080/api/v1/ledger/accounts?holder_type=user&holder_id=u_alice&asset_code=POINT'

# 该用户全部资产
curl -s 'http://127.0.0.1:8080/api/v1/ledger/accounts?holder_type=user&holder_id=u_alice'

# 按 biz_no 流水
curl -s 'http://127.0.0.1:8080/api/v1/ledger/entries?biz_no=campaign:demo:alice:point'

# 按持有人分页流水
curl -s 'http://127.0.0.1:8080/api/v1/ledger/entries?holder_type=user&holder_id=u_alice&asset_code=POINT&limit=50&offset=0'

# 冻结单
curl -s 'http://127.0.0.1:8080/api/v1/ledger/freezes?biz_no=order:demo:alice:fz:O1001'
curl -s 'http://127.0.0.1:8080/api/v1/ledger/freezes?holder_type=user&holder_id=u_alice&status=frozen'

# Journal
curl -s 'http://127.0.0.1:8080/api/v1/ledger/journals/jnl_xxx'
```

租户用 header：`-H 'X-Tenant-Id: t_mall'`。

## 8. 错误码

| code | HTTP | 含义 |
|------|------|------|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数错误 / 资产未注册 / 资产未启用 / 账户已停用 / 未知租户 / Capture 金额过大 |
| 40100 | 401 | Gateway：未知 client、缺签名、时间戳无效或超窗、签名失败 |
| 40301 | 403 | ACL 无权，或 Gateway `source_system`≠`client_id`，或租户已停用 |
| 40401 | 404 | 账户 / 冻结单 / 原单流水不存在 |
| 40901 | 409 | 幂等冲突但请求哈希不一致 |
| 42201 | 422 | 余额不足 |
| 42202 | 422 | 冻结单不是 frozen，不能 Capture/Release |
| 42203 | 422 | 兑换滑点超 `tolerance` |
| 42204 | 422 | 跨分片且无法走系统科目路径时的 Transfer 拒绝（当前实现会改走两段，一般不再直接返回） |
| 42901 | 429 | 限额或 Gateway RPS |
| 50000 | 500 | 内部错误 |
| 50101 | 501 | 能力未装配（如未注入 Fx/Jobs） |
| 50200 | 502 | Connector 调账本失败 |

## 9. Go SDK（`pkg/client`）

```go
import "github.com/davveo/ledger-hub/pkg/client"

cli := client.New("http://127.0.0.1:8088", "campaign", "dev-secret-campaign")

raw, err := cli.Credit(ctx, map[string]interface{}{
    "source_system": "campaign",
    "biz_type":      "signin",
    "biz_no":        "campaign:signin:u123:20260817",
    "holder":        map[string]string{"type": "user", "id": "u_123"},
    "asset_code":    "POINT",
    "amount":        "100",
})

res, err := cli.Exec(ctx, client.Command{
    Command:      "Freeze",
    SourceSystem: "order",
    BizType:      "order_freeze",
    BizNo:        "order:freeze:O1",
    Holder:       client.Holder{Type: "user", ID: "u_123"},
    AssetCode:    "POINT",
    Amount:       "50",
})

accounts, _ := cli.AccountsByHolder(ctx, "user", "u_alice", "POINT")
entries, _ := cli.Entries(ctx, "user", "u_alice", "POINT", 50, 0)
freezes, _ := cli.FreezesByHolder(ctx, "user", "u_alice", "POINT", "frozen")
journal, _ := cli.Journal(ctx, res.JournalID)
```

`New(baseURL, clientID, secret)` 会自动填 `X-Client-Id` / `X-Timestamp` / `X-Signature`，超时 10s。`Credit`/`Debit`/… 返回网关原始 JSON；`Exec` 解析为 `CommandResult`。HTTP ≥300 时返回 `fmt.Errorf("http %d: %s", ...)` 且带响应 body。

方法：`Credit` `Debit` `Freeze` `Capture` `Release` `Transfer` `Exchange` `Reverse`、`AccountsByHolder`、`Entries`、`Journal`、`FreezesByHolder`。

## 10. Connector 样板（`:8090`）

独立进程，把业务事件译成标准命令，经 Gateway 调账本。密钥来自 `gateway.clients`。**不是**订单/支付产品，不维护订单状态机。

### 10.1 订单 `POST /connector/order/events`

| event | 账本命令 | biz_no |
|-------|----------|--------|
| `created` | Freeze | `order:freeze:{order_id}` |
| `paid` | Capture | `order:capture:{order_id}`，`related_biz_no=order:freeze:{order_id}` |
| `cancelled` | Release | `order:release:{order_id}` |

`asset_code` 默认 `POINT`。`paid`/`cancelled` 可带 `freeze_id`。

```bash
curl -s -X POST http://127.0.0.1:8090/connector/order/events \
  -H 'Content-Type: application/json' \
  -d '{"event":"created","order_id":"O20260814001","user_id":"u_123","asset_code":"POINT","amount":"50"}'

curl -s -X POST http://127.0.0.1:8090/connector/order/events \
  -H 'Content-Type: application/json' \
  -d '{"event":"paid","order_id":"O20260814001","user_id":"u_123"}'

curl -s -X POST http://127.0.0.1:8090/connector/order/events \
  -H 'Content-Type: application/json' \
  -d '{"event":"cancelled","order_id":"O20260814002","user_id":"u_123"}'
```

### 10.2 支付 `POST /connector/pay/events`

| event | 账本命令 | biz_no |
|-------|----------|--------|
| `paid` | Credit | `pay:credit:{pay_id}` |
| `refund` | Credit（非 Reverse） | `pay:refund:{pay_id}`，`related_biz_no` 默认 `pay:credit:{pay_id}` |

pay ACL **只有 Credit**，样板退款不能走 Debit/Reverse。`asset_code` 默认 `BALANCE_CNY`。

```bash
curl -s -X POST http://127.0.0.1:8090/connector/pay/events \
  -H 'Content-Type: application/json' \
  -d '{"event":"paid","pay_id":"P988331","user_id":"u_123","asset_code":"BALANCE_CNY","amount":"10000"}'
```

### 10.3 文件 MQ

`POST /connector/mq/events`，body 加 `"topic":"order"` 或 `"pay"`。或把 JSON 放到 `connector.mq_dir`（默认 `data/mq`），文件名 `*.json`，成功处理后改名为 `*.done`，轮询间隔 `mq_interval`（默认 2s）。

## 11. 对账（业务侧）

业务日终可提交应记账清单（L1）。不传也会跑 L2/L3/L4。

```bash
curl -s -X POST http://127.0.0.1:8080/api/v1/ledger/reconcile/jobs \
  -H 'Content-Type: application/json' \
  -d '{
    "date": "2026-08-17",
    "source_system": "order",
    "asset_code": "POINT",
    "biz_lines": [
      {"biz_no": "order:freeze:O1", "command": "Freeze", "asset_code": "POINT", "amount": "50"}
    ]
  }'
```

L5 渠道对账用 `channel_lines`（字段同 `biz_lines`）。差异工单只记录差异；**补账/冲正必须再调命令**，关闭工单见运营手册。

## 12. 演示账号（联调用）

API 启动写入，可重复执行。默认租户 `t_default`。

| holder | 资产 | 演示余额（最小单位） | 展示 |
|--------|------|----------------------|------|
| `u_alice` | POINT | available 7050，frozen 600 | 7050 / 冻 600 |
| `u_alice` | BALANCE_CNY | 1049900 | **10499.00** |
| `u_alice` | BALANCE_USD | 14000 | **140.00** |
| `u_bob` | POINT | 3800 | 3800 |
| `u_carol` | POINT | 0（已被 Reverse） | 0 |
| `u_dormant` | POINT | 120，账户 **disabled** | 不可再记账 |
| `m_shop` | BALANCE_CNY | 收到 alice 转账 50000 | 500.00 |

## 13. 接入方不要做的事
