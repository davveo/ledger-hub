## 系统一句话说明

Ledger Hub 是统一的虚拟资产记账中台，负责把余额、积分、金币和多币种资产记清楚，并提供冻结、转账、兑换、流水和对账能力。

它不负责订单状态、库存、支付渠道、优惠券生命周期或会员等级。

## 重要接入原则

> App、小程序和 H5 等 C 端客户端不能直接调用 Ledger Hub，也不能保存 Gateway 密钥。

标准调用链：

```text
C 端 → 业务服务端 → Gateway → Ledger API → MySQL
                         └──── Worker（过期、对账等后台任务）
```

业务服务端负责用户身份验证和业务规则；Ledger Hub 只接受标准记账命令。

## 本地访问入口

| 服务 | 默认地址 | 用途 |
|---|---|---|
| Ledger API | `http://127.0.0.1:8080` | 开发环境直连 |
| Gateway | `http://127.0.0.1:8088` | 标准服务端接入入口 |
| Worker | `http://127.0.0.1:8089` | 后台任务进程健康检查 |
| Connector | `http://127.0.0.1:8090` | 订单、支付事件接入样板 |
| 运营后台 | `http://127.0.0.1:8080/console` | 本地运营管理 |
| OpenAPI | `/api/v1/ledger/openapi.yaml` | API 规范 |

生产环境的域名、租户、client ID、密钥和 Console Token 由管理员另行分配。

## 文档口径

- 金额字段均使用资产的最小单位整数，并在 JSON 中以字符串传递。
- `available` 表示可用余额，`frozen` 表示冻结余额。
- 账户总额为 `available + frozen`。
- 文档以当前仓库代码为准；环境权限和限额仍以实际部署配置为准。
