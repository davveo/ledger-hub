Ledger Hub Architecture

通用账本中台 · Go + Gin + GORM · 分层可独立部署 · 草案 v0.2

独立部署单元

  • • Gateway :8088 — 鉴权 / 限流 / 审计
  • • API :8080 — 记账命令 HTTP 内核
  • • Worker :8089 — 超时释放 / 对账任务
  • • Connector — 业务 MQ → 标准命令（可选）

记账内核

  • • Credit / Debit / Freeze / Capture / Release / Transfer
  • • 幂等键 tenant+source+biz_no+command
  • • 账户行锁 + 乐观锁，金额最小单位整数
  • • Exchange / 汇率快照 / Journal 预留 Phase 3

数据与一致性

  • • MySQL 主库强一致写入，流水不可丢
  • • Redis 仅只读缓存，写入后删除
  • • 一币种一资产一账户，禁止混币
  • • 对账按 asset_code 分文件，禁止折本币混加
