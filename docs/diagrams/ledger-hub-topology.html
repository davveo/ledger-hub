Ledger Hub Topology

P0/P1 实现：Gateway 鉴权 → API 记账内核 → Worker 租约作业 → MySQL 分片

鉴权边界

  • • 生产流量只进 Gateway :8088
  • • V2 覆盖 method/path/query/tenant/nonce/body hash
  • • nonce 窗口内唯一，重复 40102
  • • client.tenants 白名单；跨租户查询 40401

记账内核

  • • 幂等键 tenant+source+biz_no+command
  • • 同片 Transfer 字典序加锁；跨片 Saga
  • • 纠错只走 Reverse，运营无任意加减
  • • 对账 HTTP 202 入队，Worker drain

运行与数据

  • • Worker 每任务独立 DB 租约，过期可接管
  • • 生产关闭 AutoMigrate，走 ledger-migrate
  • • 密钥环境变量；prod 拒绝 dev-*
  • • /livez /readyz /metrics + W3C trace
